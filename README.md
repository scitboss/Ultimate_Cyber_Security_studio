<div align="center">

> **SCIT-BOSS Ultimate Cyber Security Studio** is a **professional-grade, modular website security auditing platform** built entirely with **Python 3.11+ and Tkinter** — with **zero external dependencies**.

> It performs **non-intrusive, authorized security audits** across **124+ individual tools** spanning **13 security categories**. Every tool runs **independently** with its own UI, scan engine, and results view.

<h2 align="center">🚀 Installation</h2>

<div align="center">

### Requirements

# 1. Clone the repository
git clone https://github.com/scitboss/Ultimate_Cyber_Security_studio.git

# 2. Navigate
cd Ultimate_Cyber_Security_studio

# 3. Run
python3 Ultimate_Cyber_Security_studio.py
